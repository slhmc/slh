# README button assets

Buttons use the original supplied button-slh.png background and SLH logo.
Lettering is Pixeloid Sans Bold, converted to vector outlines for consistent rendering.
Pixel icons come from the supplied Pixelarticons 2.4.2 pack.
PNG files are raster exports of the editable SVG designs.

- Pixeloid Sans: GGBotNet, SIL Open Font License 1.1 (PIXELOID-OFL.txt).
- Pixelarticons: MIT (PIXELARTICONS-LICENSE.txt).
