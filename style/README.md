# Документация интерфейса SLH

Перед изменением интерфейса прочитайте правила и актуальное поведение. Все ссылки ниже относятся к одной системе SLH; отдельные стили для новых страниц не вводятся.

| Документ | Для чего читать |
| --- | --- |
| [UI_STYLE_GUIDE.md](UI_STYLE_GUIDE.md) | Обязательные правила темы, компонентов, текста и компоновки |
| [INTERACTION_CONTRACT.md](INTERACTION_CONTRACT.md) | Принятые UX-решения: как выглядит и работает интерфейс, где реализован, как проверять |
| [DESIGN.md](DESIGN.md) | Краткая карта визуальной системы и актуальных решений |
| [LAUNCHER_STYLE_REFERENCE.md](LAUNCHER_STYLE_REFERENCE.md) | Подробные размеры, варианты и устройство экранов; исторические разделы читать с актуальными уточнениями |
| [UI_CONSISTENCY_AUDIT.md](UI_CONSISTENCY_AUDIT.md) | Наблюдения и ограничения обследования конкретной версии |

Общие правила работы с репозиторием и установки — [AGENTS.md](../AGENTS.md), правила строк интерфейса — [LANGUAGES.md](../LANGUAGES.md). История внедрения и проверки сценариев находятся в [отчёте UX-аудита](../docs/ux-audit-implementation.md) и [документации локальных серверов](../docs/local-server-settings.md).

При новом согласованном решении обновляйте соответствующее правило и ближайший пример реализации. Отличайте фактическое поведение, целевое требование и непроверенное предположение. Не объявляйте результаты браузерного preview подтверждением работы реального WebView на другой ОС.
