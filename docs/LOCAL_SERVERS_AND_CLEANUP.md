# Локальные серверы и очистка хранилища

В SLH 0.2.1 локальные Java-серверы находятся в разделе «Лок. серверы» после «Обзор». Редактор списка адресов Minecraft (`servers.dat`) остаётся отдельным инструментом.

## Создание сервера

1. Откройте «Лок. серверы» → «Создать сервер».
2. Выберите Minecraft, ядро и конкретную доступную сборку. Поддерживаются Vanilla, Fabric, Forge, Quilt, NeoForge, Paper, Purpur, Spigot, Bukkit и собственный JAR.
3. Настройте Java, память, JVM-флаги, мир и доступ. Просмотрите команду запуска.
4. Прочитайте Minecraft EULA и подтвердите её принятие отдельной галочкой.

Spigot и Bukkit собираются через официальный BuildTools. Для них нужен полный JDK нужной версии и Git. SLH устанавливает управляемый JDK отдельно от клиентской Java; путь к установленному Git можно выбрать вручную. Инструкция доступна в форме. Настройки Git для сборки изолированы от пользовательской конфигурации.

Для Java нельзя использовать путь с родительской папкой, имя которой заканчивается на `!`: это конфликтует с адресацией ресурсов JAR. Paper, Purpur, Spigot и Bukkit дополнительно требуют путь вообще без `!` и `+`. Кириллица, пробелы, `%` и `&` поддерживаются.

## Настройки и папки

«Настройки → Серверы» задаёт значения для следующих созданных профилей. Изменение этих значений не меняет существующие серверы. Стандартная папка — `data/servers` в папке данных SLH; для portable-установки `E:\SLH` это `E:\SLH\data\servers`.

Группы являются настоящими вложенными папками. Создание, переименование и перенос отражаются на диске. Переносить серверы и менять их конфигурацию можно после остановки. Изменение основной папки не переносит старые серверы.

В расширенном редакторе `server.properties` сохраняются неизвестные параметры и комментарии. Поля памяти отвечают за `-Xms` и `-Xmx`; дублировать их в пользовательских JVM-аргументах нельзя. Установленные версии ядер фиксируются: для другого ядра или версии создайте новый профиль.

## Запуск и консоль

Сервер работает в отдельном процессе `server-host`. Закрытие SLH оставляет сервер запущенным; после открытия лаунчер восстанавливает управление и вывод консоли. Закрытие окна консоли закрывает только просмотр.

Кнопка остановки отправляет `stop`, чтобы Minecraft сохранил мир. Принудительное завершение — отдельное действие с подтверждением. Если управляющий процесс потерян, SLH показывает потерю управления и не объявляет живую Java остановленной.

Можно создать самостоятельный `start.bat` для Windows или `start.sh` для macOS/Linux. Скрипт запускается из собственной папки и использует текущую Java и аргументы. Для перезаписи уже существующего скрипта требуется отдельное подтверждение. Запуск скрипта вне SLH не считается управляемым запуском лаунчера.

## Очистка

В «Настройки → Хранилище» нажмите «Анализировать файлы». Категории и отдельные файлы изначально не выбраны. Перед удалением SLH показывает выбранные пути и ожидаемый объём; затем — фактический результат, пропуски и ошибки.

Миры, аккаунты, настройки, пользовательские моды, резервные копии и используемые зависимости не являются мусором. Неизвестные файлы пропускаются. Символические ссылки и Windows junction не обходятся. Перед удалением пути, зависимости и отпечатки файлов проверяются заново. На время активных установок и работы серверов очистка недоступна.

ZIP из папки загрузок браузера предлагаются только при наличии записи успешного импорта и совпадении хэша. Чужие загрузки и архивы незавершённых установок не предлагаются. Оптимизация базы данных выполняется отдельным действием.

## Загрузки и зависимости модов

Существующая настройка параллельных загрузок принимает значения от 1 до 32; стандартное значение — 16. Новое значение применяется к следующим пакетам без прерывания текущих передач. История проверенных передач изначально свёрнута и загружается при раскрытии.

При установке Fabric/Quilt-зависимости SLH проверяет идентификатор мода внутри JAR. После проверки новых файлов старые активные версии того же мода перемещаются в резервные копии. Это также работает для вручную установленных модов и модов другого провайдера. Отключённые и нераспознанные JAR остаются на месте; при сбое скачивания исходные файлы сохраняются.

## Библиотека, подключение папок и плагины

Библиотека серверов поддерживает карточки, значки, список и сортировку. Существующие серверы из основной папки видны со статусом «Найден на диске»; кнопка подключения добавляет профиль без пересоздания файлов. При необходимости используйте «Найти серверы на диске». Выберите сервер и откройте его страницу: консоль, плагины и настройки находятся в отдельных разделах. Подробности и проверки: [рабочая область серверов](SERVER_WORKSPACE_2026-10-20.md).
