# Актуальное состояние

«Рандом» и блок на главной убраны по запросу пользователя. Обычный каталог обзора остаётся доступен. Описание ниже относится к прежней реализации.

# Рандом сборок

На главной и в обзоре остаётся только «Рандом». Старый поиск по вопросам
больше не открывается. Обычный поиск каталога в обзоре сохраняется.

Общий Dialog large содержит жанры и условие по скачиваниям: любое число,
строго больше X, строго меньше X, ближе к X. Без выбранных жанров подходят
все; при нескольких достаточно любого выбранного жанра. Неотрицательное
целое число проверяется до запроса. Условие не ослабляется автоматически
при пустом результате. Прогресс идёт в общей кнопке, ошибки и отсутствие
совпадений показаны явно; Escape возвращает фокус инициатору.

Алгоритм использует доступные Modrinth/CurseForge, сортировку по скачиваниям,
двоичный поиск позиции порога и ограниченные окна каталога. CurseForge
ограничен первыми 10000 позициями, как в существующем адаптере. Жанры
сопоставляются по категориям, названию и описанию. «Ближе» означает минимум
расстояния среди найденных подходящих проектов; не обещает исчерпывающий
глобальный минимум по каталогам. Это ограничение кратко указано в форме.

После выбора открывается `/discover?type=modpack&source=...&project=...`.
Страница использует существующие детали проекта: описание Markdown, галерею,
версии, статистику и установку через прежний диалог. Общая карточка каталога
сохраняет свой прежний диалог; отдельная страница нужна результату Random.
Сводка выбранного проекта хранится в sessionStorage для обновления страницы;
недоступная ссылка без сводки показывает возврат в обзор и повторный выбор.
Фильтры также сохраняются в пределах сеанса. Повторный выбор исключает текущий
ID и совпадающее название в другом каталоге. Данные аккаунтов не используются.

Визуальные аналоги: существующий Dialog, кнопки Button и чипы жанров;
полная страница повторно использует детали Discover. Новых цветов/радиусов нет.
Шапка страницы компактная, содержимое прокручивается внутри общей страницы.

Проверка: npm check:ui/build/test; Rust core/Tauri tests; Playwright 800×560 и
1440×900, RU/EN/DE, строгие пороги, ближайший результат, переход/обновление,
установка, повторный выбор, offline/empty и клавиатурный возврат фокуса.
Провайдеры в браузерных тестах изолированы; реальные модпаки не устанавливались.
Снимки: artifacts/ui/random-filters-* и random-project-*.

Результат проверки: UI-аудит 2268 значений, production build, 216 frontend-тестов, 254 теста ядра (6 сетевых пропущены), 11 тестов оболочки и 5 сценариев Playwright.
