# Проверка функций лаунчера

31 октября 2026; рабочая копия 0.2.2+1 с существующими незакоммиченными изменениями. Сквозные сценарии используют браузерный preview и тестовые данные; реальные аккаунты, игровые файлы и пользовательские серверы не запускались и не изменялись.

| Область | Что проверялось |
| --- | --- |
| Оболочка и навигация | Маршруты и порядок разделов, переходы, возврат из отсутствующей сборки, контекстные меню и их границы |
| Библиотека | Три вида, меню карточек, выбор, перетаскивание, удаление с индикацией прогресса, группы |
| Создание и каталог | Версии Java, Rust/Horizon и CurseForge, выбор релиза, описание модпака, ошибки установки и повтор, Modrinth/CurseForge в preview |
| Аккаунты и скины | Окно внешности, вкладки и стрелки клавиатуры, галереи, локализация, режим офлайн, размеры и reduced motion |
| Сборка | Оформление и содержимое, файловые вкладки и перенос файлов, консоль, настройки версии Horizon, ошибки и отчёты |
| Локальные серверы | Создание и EULA, ядра, Java и порт, библиотека и группы, вкладки и меню, консоль и перезапуск, показатели, восстановление ядра, плагины, списки игроков, удаление и внешний конфликт настроек |
| Настройки | Внешность, масштаб, уведомления, Java, Bedrock, загрузки, синхронизация, консоль, конфиденциальность и хранилище; охват определяется соответствующими тестами |
| Сетевые серверы сборки | Загрузка, переключение сборки при задержке, запрет изменений во время загрузки/удаления, отмена через Escape и подтверждение удаления |

Исправлены два дефекта: старый список сетевых серверов больше не остаётся доступным при переключении сборки и устаревший ответ не заменяет актуальный; повторные сочетания Ctrl+плюс/минус сохраняются последовательно. Для удаления записи используется общий диалог. Снимки нового диалога: `artifacts/ui/network-server-dialog-800.png` и `artifacts/ui/network-server-dialog-1440.png`.

Проверки: `npm run check:ui`, `npm run build`, `npm test` (171), `cargo test --manifest-path src-tauri/Cargo.toml` (11), `npx playwright test --reporter=line` (82), специальные сценарии `network-server-safety` и `zoom-repeat`. Полный e2e-прогон использует имитации и не подтверждает реальную загрузку, запуск Minecraft, авторизацию, платёжные сервисы, файловые системные диалоги или все сочетания пользовательских расширений. Предыдущий полный UI-прогон имел известный отдельный сбой теста ожидания скрытого FPS-ползунка; текущее поведение оставляет его видимым и отключённым.
