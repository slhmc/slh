# Загрузки CurseForge

В «Настройки → Загрузки» можно выбрать папку браузерных загрузок CurseForge. По умолчанию используется системная папка «Загрузки». Выбор применяется и к поиску модов, для которых автор разрешил скачивание только с сайта.

Автоматический импорт выключен по умолчанию. При включении SLH каждые 5 секунд проверяет ZIP в выбранной папке, ждёт неизменной сигнатуры файла на двух проверках и распознаёт манифест CurseForge. Незавершённые загрузки и архивы других форматов не импортируются. Установка появляется в обычном окне прогресса; недостающие файлы можно скачать с сайта и продолжить. Успешно импортированные файлы отмечаются в базе, чтобы повторный запуск не создавал дубликаты.

Удаление исходников включается отдельно. После успешной установки Minecraft, загрузки зависимостей и размещения содержимого сборки SLH удаляет ZIP из выбранной папки или своего кеша загрузки сборок, а также соответствующие моды, ресурспаки и шейдеры из выбранной папки и ручного кеша. Перед удалением проверяются имена и SHA-1. Другие файлы и содержимое установленных сборок не удаляются. При ошибке или отмене установки исходники сохраняются.

Скачивание Bedrock Preview отключено. Preview, уже установленный через Microsoft Store/Xbox, остаётся доступен в каталоге SLH. Windows отклоняет регистрацию распакованного пакета поверх существующего пакета Store с той же идентичностью (`0x80073CFB`); SLH не удаляет Store Preview для обхода этого ограничения.
