# Игра с друзьями

Обоим игрокам нужен запущенный SLH. Список друзей хранится локально; выбранный аккаунт задаёт имя профиля. Для нового соединения нужно обменяться приглашением и ответом. Игровые данные идут напрямую, публичный STUN помогает установить соединение.

## Один раз: добавьте друг друга

1. Откройте «Друзья» → «Добавить друга».
2. Скопируйте свой код контакта и отправьте другу. Попросите его код в ответ.
3. Вставьте код друга и нажмите «Проверить контакт».
4. Сверьте отпечаток с другом через привычный доверенный канал и подтвердите добавление. Друг должен добавить вас таким же способом.

Код контакта сохраняет доверие к лаунчеру. Если друг сменил игровой аккаунт, повторно импортируйте его код контакта, чтобы обновить имя. Замена исполняемого файла не удаляет друзей. При переносе данных на другой компьютер или к другому пользователю Windows может понадобиться новое добавление: закрытый ключ защищён средствами системы.

## Для каждой игры: установите соединение

1. Хозяин запускает мир и выбирает в Minecraft «Открыть для сети» либо запускает локальный сервер SLH.
2. В списке друзей хозяин нажимает «Открыть доступ», выбирает мир или сервер и создаёт приглашение. Если порт не определился, его можно указать вручную: нужен порт мира или сервера на компьютере хозяина.
3. Гость нажимает «Присоединиться», вставляет приглашение и создаёт ответ. Ответ нужно отправить хозяину.
4. Хозяин вставляет ответ в окно соединения и нажимает «Подключить».
5. После состояния «Подключено» гость копирует **локальный адрес для Minecraft** и вводит его в прямом подключении игры. Это адрес на компьютере гостя; отправлять его хозяину не нужно.

Приглашение и ответ действуют десять минут; часы обоих компьютеров должны быть синхронизированы. После закрытия окна действующий код можно снова открыть через «Подробнее». После перезапуска SLH или разрыва соединения создайте новое приглашение. Во время игры оба лаунчера должны оставаться запущенными; закрытие окна соединения не отключает доступ, кнопка «Отключить» — отключает. Удаление друга закрывает его соединения.

## Если Minecraft не пускает игрока

Проверка друга в SLH и проверка игрового аккаунта Minecraft работают отдельно. Ошибка `Invalid session` не доказывает сбой туннеля; причину нужно искать в журналах игры и системе авторизации сервера.

Для совместной игры Microsoft, Ely.by и офлайн-аккаунтов настройки мира или сервера должны разрешать эти аккаунты. Для одиночного LAN-мира может понадобиться совместимый мод у хозяина, например LAN Server Properties / LAN World Plug-n-Play. Для локального сервера есть настройка `online-mode`, изменение которой требует перезапуска. SLH не меняет её автоматически.

Перед отключением проверки аккаунтов учитывайте: UUID и связанные с ним инвентари могут измениться, а имена игроков перестают проверяться. Исходный LAN-порт остаётся доступен согласно настройкам самого Minecraft, локальной сети и брандмауэра; отзыв друга закрывает только туннель SLH.

Если само прямое соединение не устанавливается, создайте новое приглашение и проверьте доступ к сети. Некоторые сочетания NAT и брандмауэров блокируют P2P. В этой версии нет ретранслятора, поэтому подключение через любую сеть не гарантируется.
