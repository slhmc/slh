# SLH 0.2.4

## English

### Major changes
- Expanded artwork editor for instances and servers, with images, rotation, snapping and undo/redo.
- Added Java crash diagnostics and redesigned local-server settings.
- Reworked sync setup and added configurable interface animations.

### Improvements
- Tile/list actions, panel docking and remembering the last settings section.
- Unified home character controls and refined interface scaling.

### Fixes
- Improved Bedrock version checks, content filters and addon imports.
- Fixed Horizon loading/retry, server stopping and configuration updates.
- Fixed artwork layout, sync source selection and navigation highlighting.

## Русский

### Крупные изменения
- Расширен редактор оформления сборок и серверов: изображения, поворот, привязки и отмена/возврат.
- Добавлена диагностика вылетов Java, переработаны настройки локальных серверов.
- Обновлено создание синхронизаций, добавлены настраиваемые анимации.

### Улучшения
- Действия плитками или списком, перемещение панелей и запоминание раздела настроек.
- Объединены настройки персонажа на главной, уточнён масштаб интерфейса.

### Исправления
- Улучшены проверки версии Bedrock, фильтры контента и импорт аддонов.
- Исправлены загрузка Horizon, повтор запросов, остановка и настройка серверов.
- Исправлены отображение значков, выбор источника синхронизации и подсветка навигации.
