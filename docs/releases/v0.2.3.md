# SLH 0.2.3

## English
- Fixed launcher startup on existing profiles after migration checksum differences.
- Restored instance actions as buttons in the side panel.
- Improved update detection, Horizon and local-server controls.

## Русский
- Исправлен запуск лаунчера с существующими данными после ошибки проверки миграций.
- Кнопки действий сборки возвращены в боковую панель.
- Улучшены проверка обновлений, Horizon и управление локальными серверами.
