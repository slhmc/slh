# SLH 0.2.3

## English
- Fix update detection and support release numbers with additional numeric parts. This release provides the transition from 0.2.2 / 0.2.2.1.
- Improve Horizon client/server integration and reuse verified resources. Horizon remains experimental and requires compatible hardware and releases.
- Improve local-server controls, live settings, player lists and configuration feedback.
- Refine instance headers, confirmations, translations and appearance compatibility.

## Русский
- Исправлено обнаружение обновлений и добавлена поддержка номеров с дополнительными числовыми частями. Этот выпуск обеспечивает переход с 0.2.2 / 0.2.2.1.
- Улучшены клиент и сервер Horizon, повторно используются проверенные ресурсы. Horizon остаётся экспериментальным и требует совместимого оборудования и релизов.
- Улучшены управление локальными серверами, настройки во время работы, списки игроков и сообщения настройки.
- Уточнены шапки сборок, подтверждения, переводы и совместимость оформления.

## Downloads / Скачать
Windows x64: EXE, MSI, portable ZIP. macOS Intel / Apple Silicon: DMG, app ZIP. Linux x64: AppImage, DEB, RPM. See assets below / Файлы ниже.
