# SLH v{{VERSION}} — Horizon improvements and interface refinements

This pre-release improves experimental Minecraft on Rust, installation reliability and the home screen.

## Minecraft on Rust: Horizon

- Choose Rust alongside Java and Bedrock when creating an instance. The Minecraft list contains versions supported by compatible Horizon releases; choose the Horizon release separately.
- Fix duplicate instance names when installing multiple Horizon releases for the same Minecraft version. New instances receive an available suffix and keep their own selected release.
- Download Minecraft files and assets in parallel and reuse verified files between instances. Content-addressed caching prevents releases with different library contents from overwriting each other.
- Horizon's native client and preparation tool are used directly; a separate Horizon Launcher installation is not required. The Rust icon now follows the original logo in a pixel style, and the creation screen explains its states more clearly.
- Opt in to synchronizing Rust instances with configured shared files. They remain excluded until the setting is enabled.

Horizon is experimental and currently requires Windows x64, Vulkan and a Microsoft account owning Minecraft Java Edition. Java is used for preparation. Java mods are not supported. [Horizon project](https://github.com/horizon-rust/horizon)

## Home and library

- Add an option for the 3D character to follow the cursor. In compact settings, cursor tracking and character FPS share one card; unavailable controls appear disabled.
- Refine Rust's beta badge, FAQ and settings layout. Show loader names with their versions and improve progress text in list view.
- Hide an instance immediately during deletion and show the actual cleanup progress; report failures and restore the card. Deletion is disabled while an instance is being installed.
- Drag local mods, resource packs and shaders into the appropriate instance tab. Hover over a tab to open it; imported files are copied without overwriting existing files.
- Remove the unused instance layout setting and refine compact character controls.
