## Сборка и продолжение

- Отдельный helper собирается scripts/build-server-host.mjs и встраивается в Tauri. Версионированные копии извлекаются при запуске сервера в data/server-runtime/<hash>.
- Скрипт доработан для target triple, сборки под native используют старый target cache, cross — свой. Ожидаемый helper: `.generated/server-host/x86_64-pc-windows-msvc/slh-server-host.exe`.
- Release helper уже собирался успешно (7m39s), но после этого исходники изменялись — пересобрать.
- npx tauri build --no-bundle был **отменён намеренно на устаревшем slh_lib**, поскольку в это время нашли и исправили новые ошибки. Журнал artifacts/local-servers-native-build.log с exit 0xffffffff отражает остановку компилятора, не подтверждённую ошибку исходников.
- Для сокращения больших будущих Tauri async state machines тяжёлые новые команды используют FutureExt::boxed(). Последнюю native сборку после этого ещё не запускали.
- Перед Rust-командами: `$env:RUST_MIN_STACK='33554432'`; без этого на Windows ранее rustc падал по стеку.
- Использовать `python -X utf8` и encoding='utf8' для чтения/записи текстов (иначе cp1251).
- Для русских интерфейсных текстов применялись sasha, better-ui/better-typography из предыдущей части; также прочитан react-best-practices.
- Не запускать executable прямо из cargo target при его пересборке: Windows блокирует линкер. Копировать тестеры в artifacts/server-validation с отдельным именем, иначе LNK1104.
- Не запускать разные cargo test с перенаправлением в один и тот же журнал одновременно.
- При повторной смене SQL миграции 0021 старые изолированные тестовые базы получают checksum mismatch. Пользовательская E:\SLH база ещё эту миграцию не получала; существующие миграции не менять. Для новых тестов брать новый isolated root либо использовать уже соответствующие базы.
