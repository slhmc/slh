# Модпаки CurseForge

Лаунчер устанавливает ZIP-сборки CurseForge по `manifest.json`: версия Minecraft и загрузчика берётся из манифеста, а каждый файл скачивается по указанным `projectID` и `fileID`. Папка `overrides` переносится в игровую папку, включая настройки и сохранения. Архивы миров из списка файлов распаковываются в `saves`. Для Modrinth используется отдельный формат `.mrpack`.

В окне установки CurseForge можно выбрать версию Minecraft и выпуск сборки. Для получения метаданных достаточно встроенного SLH relay; личный API-ключ необязателен.

ZIP-файл можно выбрать через «Импорт → Архив». Окно импорта показывает версию Minecraft и загрузчика, сохраняет ошибку и позволяет повторить импорт или выбрать недостающие файлы.

Запросы к CurseForge проходят через общую очередь с паузой не менее секунды. При HTTP 429 лаунчер учитывает `Retry-After` и повторяет запрос. Ответы сохраняются локально с ограниченным сроком действия, поэтому повторная попытка и перезапуск не требуют заново запрашивать все метаданные. Первая подготовка большой сборки может занять несколько минут.

Если автор файла отключил скачивание через сторонние лаунчеры, SLH показывает список таких файлов со ссылками на конкретные версии. Скачайте их на сайте CurseForge, нажмите «Выбрать скачанные файлы» и выберите JAR/ZIP-файлы. Лаунчер сохранит их в `data/downloads/curseforge-manual` и повторит установку. Можно также положить файлы в эту папку самостоятельно. Принимаются только версии, SHA-1 которых совпадает с метаданными CurseForge. Пока нужные файлы отсутствуют, новый экземпляр Minecraft не создаётся.

Для `HORROR - One Block (dweller)` 1.8.5 (файл `9086419`) проверены 63 записи манифеста: 14 файлов требуют ручного скачивания, а проект `307740` содержит отдельный архив мира. Полная установка этой сборки требует предоставления этих 14 файлов.

Проверка на скачанном архиве выполняется отдельно от пользовательских экземпляров:

```powershell
$env:SLH_CURSEFORGE_PACK_FIXTURE = 'E:/SLH/data/downloads/curseforge-packs/1204182-9086419.zip'
cargo test --manifest-path crates/slh-core/Cargo.toml --lib --locked one_block_horror_reports -- --ignored
```

Проверка выбора версии в окне установки использует собранный фронтенд:

```powershell
npm run build
npx playwright test --config playwright.preview.config.ts tests/e2e/curseforge.pw.ts
```

При установке закрытых для API файлов нажмите «Открыть страницы скачивания». Сохраните указанные версии в системную папку «Загрузки»: SLH проверяет её каждые три секунды, а когда обнаружит все недостающие файлы, повторяет установку с проверкой SHA-1. Поддерживаются имена с добавленным браузером суффиксом «(1)». Если браузер сохраняет файлы в другую папку, используйте «Выбрать скачанные файлы».

Установка сборки теперь отображается в библиотеке с момента отправки команды и остаётся там во время проверки архива и ожидания файлов. Нажмите её карточку, чтобы открыть точную ошибку, ссылки `/download/<ID>` и повторить установку. Закрытие окна не останавливает поиск недостающих файлов в папке «Загрузки». Для каждого файла сохраняется ID версии из манифеста сборки.

Закрытые для прямого скачивания файлы сохраняются в локальный кэш после проверки SHA-1. При повторной установке из каталога SLH также проверяет файлы уже установленных сборок с теми же ID проекта и выпуска. Оригинальные ZIP-файлы миров берутся из кэша архивов, а не из изменённых игровых сохранений. Поэтому очистка системной папки «Загрузки» не требует скачивать эти файлы заново. Разные версии с одинаковым именем хранятся отдельно по хешу.

Полная проверка установки из каталога выполнена для HORROR 1.8 (`8292539`): Minecraft 1.19.2, Forge 43.5.0, 61 запись манифеста. Архив и доступные файлы скачаны через установщик каталога, 13 закрытых файлов повторно использованы из уже установленной сборки. Проверены SHA-1 всех 61 файлов, распаковка мира и итоговый статус `installed`; Minecraft, его ресурсы и Forge установлены в отдельную тестовую папку.
