# SLH: оптимизация существующего интерфейса, 6 октября 2026

Сохраняется основной Tauri/React-интерфейс, его страницы и настоящий 3D-персонаж. Slint-прототип не используется. Установленный `E:\SLH` на этом этапе не обновляется.

## Реализованные изменения

- Ограниченный FPS планирует следующий кадр через таймер и requestAnimationFrame: между кадрами не требуется постоянное пробуждение на частоте монитора. Разрешение, свет, сглаживание и анимация сохранены.
- Сворачивание/скрытие останавливает сцены и отображаемые метрики. Через 30 секунд оба просмотрщика освобождают GPU-ресурсы; восстановление создаёт новый canvas, сохраняя скин, ракурс и масштаб.
- Windows-адаптер переводит WebView2 в Low memory target и после освобождения сцен запрашивает TrySuspend. При восстановлении вызывает Resume. Эти API работают по возможности, отказ не ломает интерфейс. Rust-загрузки и ожидание игры продолжаются.
- События прогресса объединяются до 5 обновлений в секунду на операцию. Изменение этапа, завершение и ошибки доставляются сразу. Подробные консольные события не отправляются скрытому интерфейсу, полный лог остаётся на диске.
- Последние результаты ограничены 64 событиями; активные операции доступны через снимок. Снимок и живые события объединяются по последовательности при возврате окна. Системные уведомления учитывают настройки, язык и отсутствие повторного сообщения после возврата.
- Счётчик загрузки больше не вызывает полное чтение bootstrap/SQLite на каждом изменении количества байтов. Экран консоли пропускает отрисовку невидимых строк через content-visibility; данные для поиска и копирования сохранены. Это не виртуализация DOM.
- Существующий Rust-core используется основным Tauri-приложением через адаптер событий. Выбор ОС/архитектуры Java, архивов и Minecraft native-библиотек платформенный. Правила версии ОС получают формат Java: major.minor Windows, release ядра Linux, версию продукта macOS. На macOS добавляется XstartOnFirstThread.
- Языковые ресурсы ищутся также в каталоге ресурсов приложения, переданном Tauri-хостом. Bedrock недоступен вне Windows. Защита учётных данных: DPAPI / Keychain / Secret Service, без открытого fallback.
- Платформенные конфигурации упаковки и GitHub Actions: Windows x64, Linux x64, macOS Intel и Apple Silicon. Дополнительно проверки компиляции Fedora/Arch. Архивный native-прототип запускается только вручную.

## Проверка

### Продолжение 7 октября

Computer Use отключён по запросу пользователя. Перед отключением проверено открытие библиотеки и первого перехода на главную: основной интерфейс и аккаунтный 3D-скин загрузились. Это была предварительная release-копия, а не полная визуальная приёмка финального пакета.

Frontend: 47 тестов существующего набора прошли, затем отдельно прошли 4 теста второго просмотрщика (включая 2 новых), TypeScript и production-сборка. Добавленные проверки покрывают восстановление камеры на новом canvas после освобождения скрытой сцены и игнорирование устаревшего освобождения видимого просмотрщика. На финальных исходниках прошли 99 release-тестов Rust-ядра; ранее прошли 8 тестов Tauri. Финальный release-EXE успешно собран 7 октября; отдельная проверка скомпилированного ядра подтвердила Windows os.version=10.0 и применение правил Minecraft.

Portable-пакет: `release/SLH-Tauri-20261007`, 46 003 660 байт (43,87 MiB) до добавления служебного BUILD-INFO.json. Он содержит встроенный интерфейс, лицензии и Bedrock-helper, не содержит аккаунтов, игровых данных или Fixed WebView2 Runtime. SHA-256 SLH.exe: `3E67AB91CEA21C7DC35DFB83E07E3CD99B262B4CCBCB1FD06CBF1AF573EBE796`. Регрессионная проверка упаковки прошла: обнаружение Evergreen, встроенный frontend, удаление старого runtime в одноразовом тестовом каталоге, сохранение существующих данных и запрет записи в каталог работающей копии. GUI при этих проверках не открывался.

Установленный `E:\SLH\SLH.exe` не изменён, SHA-256: `2AF5DAC8D7822873472A655B83D8E3C40BA405D383A40B70E742B904EE3A490B`.

Конфигурации JSON и YAML прошли синтаксическую проверку. Portable-упаковка дополнена лицензиями Mine3D и sysinfo. Скрипт замеров сохраняет метаданные EXE (путь, SHA-256), runtime, сценарий и реальные интервалы выборок, отклоняет завершение процесса и повторное использование PID. Проверка отсутствующего процесса проходит без создания недействительного отчёта.

После этого, по отдельному запросу пользователя, выполнено сравнение старой и новой сборок на главной 30 FPS и в свёрнутом состоянии: [отчёт от 7 октября](PERFORMANCE-COMPARISON-20261007.md). На главной CPU практически не изменился (4,057% → 4,004%); working set свёрнутого окна снизился с 476,6 до 118,8 MiB, private bytes почти не изменился. Восстановление интерфейса и персонажа после приостановки проверено. Цель низкого CPU открытой главной не достигнута. Ниже оставлена таблица исходного этапа; актуальные сопоставимые показатели находятся в новом отчёте.

Остаются проверки библиотеки, 20 переходов с настоящим WebGL, запуск Minecraft и загрузки во время приостановки. Проверки на чистых Windows 10/11 без runtime и на Linux/macOS также остаются открытыми.

Измерения: установленный release, 60 секунд прогрева и 180 секунд наблюдения. Принадлежность процессов определяется от PID SLH, Minecraft и чужие WebView исключаются. CPU нормализован по числу логических процессоров. Working set — сумма с возможным повторным учётом общей памяти; private bytes учитываются отдельно. GPU — максимальная нагрузка одного движка среди принадлежащих процессов, не суммарная загрузка видеокарты.

ZIP `release/SLH-Tauri-20261007.zip` занимает около 18,85 MiB. Размер пакета не является показателем памяти работающего приложения.

Для проверок используется отдельная копия данных, подготовленная `scripts/prepare-native-data.py`. Аргументы `--isolated --data-dir <копия>` отключают глобальное восстановление Windows Bedrock в тестовой копии. Обычный запуск сохраняет восстановление. Две оболочки на рабочей базе не запускаются одновременно.

Проверки CI требуют GitHub-репозитория. В локальной конфигурации remote отсутствует; наличие workflow не означает успешную сборку или проверку GUI на Linux/macOS. Нужны реальные сессии Windows 10/11, Linux X11/Wayland и macOS обеих архитектур, включая защищённое хранилище, загрузку Java и запуск игры. ARM64-лаунчер не гарантирует поддержку старых Minecraft-native-библиотек.

WebView2 остаётся Windows-движком существующего Tauri-интерфейса; macOS использует WKWebView, Linux — WebKitGTK. Удаление WebView2 из Windows с сохранением всего React/CSS/WebGL требует отдельного совместимого движка и проверки функций; эта работа не заменяет интерфейс упрощённой оболочкой.
