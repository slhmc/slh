# Отчёты об ошибках и восстановление сборок

SLH сохраняет локальные отчёты в `crash` внутри корня данных лаунчера. Для portable-установки `E:\SLH` это `E:\SLH\crash`. Отчёты создаются при ошибках установки, импорта, загрузки и запуска, при ненулевом завершении игрового процесса и при панике Rust в лаунчере. Принудительная остановка игры пользователем, отмена установки и ожидание ручных файлов CurseForge не считаются сбоями.

Открыть отчёт можно из уведомления или окна ошибки. Уведомление с отчётом остаётся до закрытия. Все сохранённые отчёты доступны через «Настройки → Дополнительно → Отчёты об ошибках → Открыть папку crash».

В отчёте указаны время, версия SLH, операция и этап, сборка и загрузчик, техническая причина и цепочка вложенных ошибок. При падении игры добавляются последние 48 КиБ журнала запуска и подсказки для известных ошибок памяти, Java, модов и графического окна. Подсказка основана на тексте журнала: один код выхода не позволяет достоверно определить причину.

SLH не прикладывает аккаунты, переменные окружения или аргументы запуска. Из текста удаляются известные формы токенов, паролей и параметров подписанных URL. Журналы сторонних модов могут содержать личные сообщения, имена игроков, адреса серверов и локальные пути. Перед отправкой другому человеку просмотрите отчёт; автоматически SLH его никуда не отправляет. Отчёты не удаляются автоматически.

Повторная установка незавершённого импорта Modrinth и CurseForge использует сохранённую запись импорта и ту же сборку, в том числе после перезапуска лаунчера. Проверенные файлы используются повторно; недостающие скачиваются заново. Уже применённые настройки из архива не копируются поверх пользовательских настроек при повторе. Исходный архив должен оставаться по сохранённому пути. Старые незавершённые импорты Modrinth, созданные до появления записи восстановления, такую запись не имеют.

Modrinth перебирает указанные автором HTTPS-зеркала и проверяет SHA-1 каждого файла. Серверные файлы с `client: unsupported` пропускаются. Файлы `client-overrides` имеют приоритет над общими `overrides`. Записи индекса, перекрытые этими файлами, не скачиваются поверх них.

Параллельные установки используют блокировку на путь загрузки для общих библиотек и ресурсов Minecraft. Обрыв одного запроса не должен позволять двум установкам перезаписывать один временный файл. Проверка контрольной суммы и ограничения размера действуют при повторных попытках и смене зеркала.

Ограничения распространения CurseForge сохраняются: SLH предлагает скачать запрещённые для автоматической раздачи файлы с официальных страниц и проверяет их SHA-1 перед продолжением. Ошибки сети, удалённые файлы, HTTP 429, несовместимые моды и требования Java могут мешать установке или запуску независимо от лаунчера.

Проверки разработчика: обычные Rust-тесты проверяют обрыв ответа, зеркала, параллельный доступ к кэшу, восстановление обоих форматов, ручные файлы и отчёты. Тест `live_modpack_catalog_downloads_prepare_profiles_and_explain_blocked_files` запускается отдельно с `--ignored --nocapture` и переменными `SLH_PACK_TEST_CACHE`, `SLH_PACK_TEST_JAVA`, `SLH_PACK_TEST_JAVA17`. Он использует отдельную временную базу и копии неизменяемых ресурсов Minecraft; архивы и моды загружаются из сервисов. Игру тест не запускает.

Формат Modrinth: [официальная спецификация mrpack](https://support.modrinth.com/en/articles/8802351-modrinth-modpack-format-mrpack). API CurseForge: [официальная документация](https://docs.curseforge.com/rest-api/).

## Старый Forge и повторяющиеся параметры запуска

В профиле Parasites — Reloaded (Minecraft 1.12.2, Forge 14.23.5.2860) обнаружено двойное добавление `--gameDir`, `--assetsDir`, `--version` и других параметров при объединении Minecraft и Forge. LaunchWrapper завершался с `joptsimple.MultipleArgumentsForOptionException` ещё до загрузки модов. Наличие нескольких установленных Java не являлось причиной этой ошибки.

При установке старого загрузчика SLH теперь объединяет параметры с приоритетом значений загрузчика. Уже сохранённые профили нормализуются в памяти перед запуском, без перезаписи сборки. Повторяемые параметры, включая несколько `--tweakClass`, сохраняются. Это относится к старому строковому `minecraftArguments`; современные массивы `arguments.game` обрабатываются прежним способом.

Регрессионная проверка `actual_parasites_profile_passes_launchwrapper_option_parsing_on_java8` читает установленный профиль и его `jopt-simple`, компилирует временный диагностический класс и запускает только этот класс на Java 8. Исходные аргументы воспроизводят исключение; сформированные SLH аргументы проходят проверку, включая путь с пробелами. Minecraft, Forge и моды не запускаются. Для проверки нужны `SLH_LEGACY_PROFILE`, `SLH_LEGACY_CACHE`, `SLH_LEGACY_JAVA8`, `SLH_LEGACY_JAVAC`; запуск: Rust-тесты с фильтром имени, `--ignored --nocapture`.

Путь к отчёту о падении также сохраняется в типизированном событии `LaunchState`, чтобы кнопка открытия отчёта доходила до уведомления интерфейса.
