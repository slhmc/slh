# Работа с SLH

Перед изменениями интерфейса прочитайте [правила интерфейса](docs/UI_STYLE_GUIDE.md) и [правила языковых файлов](LANGUAGES.md). Новые окна должны использовать общие компоненты, палитру и ключи переводов SLH.

Сохраняйте существующие незакоммиченные изменения. Не изменяйте пользовательские сборки, аккаунты, настройки и языковые файлы при сборке или обновлении приложения.

Проверки: `npm run check:ui`, `npm run build`, `npm test`, Rust-тесты и Playwright для затронутых сценариев. Изменения ядра делайте в `crates/slh-core`; многие модули `src-tauri/src` лишь повторно экспортируют ядро.
